# Meshtastic di Indonesia

## Apa itu Meshtastic?

Meshtastic adalah platform komunikasi berbasis LoRa mesh network.
Perangkat bisa saling kirim pesan tanpa internet dan tanpa SIM card.

## Perangkat yang Didukung

- Heltec V3
- Heltec V4
- LilyGo T3S3

## Frekuensi di Indonesia

Gunakan region AS923-2, slot 16 = 922.875 MHz.
